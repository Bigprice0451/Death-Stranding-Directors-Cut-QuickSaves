# Maintaining the Auto Save timer

Auto Save is off until the player enables it in the QuickSaves tab. The default interval is ten minutes. The enabled switch and interval are stored by ReShade under `DirectorCutQuickSaves` as `AutoSaveEnabled` and `AutoSaveMinutes`. The two save limits are stored with their respective Steam account libraries. The manual shelf starts at 100 and the timed shelf starts at 15.

`src/autosave.hpp` keeps time using Windows' monotonic clock. Half-second observations of a loaded world arm the timer. Opening the game's pause menu preserves the time left. Changing the interval, loading a world, entering a cutscene or losing the regular update stream starts a new interval when gameplay returns. At a simultaneous deadline the manual Quick Save gets priority. An ordinary manual capture between deadlines leaves the timed schedule intact.

`src/addon.cpp` checks manual keys first and asks the timer for one due observation. A render callback takes the preview. `src/session.cpp` transfers the request to the regular game update, confirms the same world is still loaded and discards timed requests older than one second. It checks the current scene at input, then again before calling the world writer or native loader. Fresh cinematic clocks and the game's cutscene, scripted acting and movie flags hold new requests. A native load or an unavailable world-state manager also holds them. The game-owned serializer can decline a busy game. An unsuccessful timer capture is dropped and logged once.

Both shelves use the same snapshot format, checksum, native writer and loader. New saves have no cinematic bookmarks. Earlier saves with an existing bookmark still use the legacy scene-resume logic when opened from normal gameplay. Manual entries live under `QuickSaves/<Steam account>` and timed entries under `AutoSaves/<Steam account>`, both beneath the add-on's data directory. A row identifies its account, shelf, physical slot, sequence and digest. The thumbnail cache reserves 100 physical slots for each shelf.

`src/library.cpp` remembers which files it has fully checked during the current game session. Each save opens every numbered slot and checks its drive, file identity, Windows change-journal number, size and modification time. An unchanged file can reuse its verified entry. A file that changed, or whose drive cannot supply a reliable change number, is read and checked against its SHA-256 checksum. A damaged or busy file occupies its slot. Saving can continue in another slot when space or a healthy rotation candidate is available. Opening the game, refreshing the browser, loading a selected save, rotating the oldest save and confirming a retention change still verify the relevant files in full. This inventory only lives in memory.

To measure storage speed, run the Release build of `quicksave_library.exe --benchmark` from a scratch folder with 550 MiB free. It fills a synthetic 100-slot shelf with 5 MiB checkpoints and times nine rotations, including the disk flush. Each rotated save is read back and compared with its input after the timer stops. The test removes its synthetic folder when it finishes. Native world capture and thumbnail encoding are outside this measurement.

`src/post_load_check.hpp` separates the arrival-position measurement from the later cargo and order comparison. The loader records Sam's position as soon as the native request returns. It then allows eight seconds for the world to exit loading and stay ready for at least 250 milliseconds before comparing inventory. A timeout is reported as unavailable.

The CTest case `timed_autosave_schedule` exercises the clock with simulated time, including ordinary pause, world transitions, missed deadlines, cinematic holds and deferred delivery comparison. `quicksave_library` exercises the storage limits and tests selection identity. For an in-game check, enable Auto Save at one minute, carry a delivery until one appears, then make a manual Quick Save. Open each entry from its own shelf and compare the saved position and cargo count. During a cutscene, a manual press should show the hold message and the timer should leave both lists alone.
